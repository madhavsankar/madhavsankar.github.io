### The challenge

Developers use different AI coding harnesses. Google Ads API tools need a consistent MCP interface and a way to identify where agent capabilities fall short or regress.

### My contribution

Developed the Google Ads API MCP server to work with MCP-capable harnesses such as Antigravity and Claude Code. Built an evaluation framework with daily health checks, regression runs, environment comparisons, alerting, and per-step tool-call, latency, and token metrics.

### Evaluation focus

- Surface capability gaps through recurring health checks.
- Identify regressions across environments.
- Track tool-call, latency, and token metrics per step.
