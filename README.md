# Madhav Sankar — Personal Website

Static, build-free portfolio site hosted on GitHub Pages. The black particle hero leads into a portfolio covering Madhav's current Google role, previous Microsoft and research experience, selected projects, education, and publications.

The site uses `index.html` for the portfolio and `archive.html` for additional projects, with shared styles in `css/portfolio.css` and interactions in `js/portfolio.js`. The current profile PDF is available at [`resume/Resume.pdf`](resume/Resume.pdf).

The visual design is inspired by [Brittany Chiang's v4 portfolio](https://v4.brittanychiang.com/); this site uses a custom static implementation and does not depend on the reference site's code or assets.
